# CI高速化の検証結果

詳細・再現手順・依存関係図は [README](README.md)、全ジョブ・step別の実測は
[measurements](measurements.md)、原データは [raw](raw/) を参照してください。

## 採用した変更

- CLI smokeとDockerから、成果物を共有していない14ジョブへの `needs: build` を削除。
- PR/mainとも全23ジョブを維持。Linux/macOS/Workers、Debug/ReleaseSafe、
  OpenSSL、scaffold/update/sync、生成clientとhost contractを削減していません。
- CIではZigのテスト成功結果を再利用せず、コンパイル済みでもテスト本体を実行。
- living examplesはコマンドごとに途中経過を保存。失敗時にも成果物を取得。
- scaffoldのNative/Workersビルド、migration、metadata検証をコマンド別に計測。
  計測ファイルを復元対象キャッシュの外へ置き、過去の結果混入を防止。
- workflow_dispatchと標準ライブラリだけの再現用計測ツールを追加。

## 実測と判断

変更前の成功4実行は全体中央値 **17分56.5秒**、総ジョブ実行時間中央値
**90分15秒**。依存関係修正後の最初の成功実行は **10分51秒**、次は
**10分38秒**で、各23/23ジョブ成功です。短縮の主因はジョブ開始待ちの削減で、
総ジョブ時間はほぼ変わりません。ホスト差があるため、全短縮をキャッシュの
効果とは主張しません。

コンパイルキャッシュは通常展開先と固定Zig展開先の2方式を試験しました。
後者では同一SHAでcold/warmを比較し、全体715→700秒（約2%）、全4キャッシュ
ヒットでしたが、Linux living examplesは647→695秒でした。CLIキャッシュは
2GiB制限の99%へ達し、別試験では上限超過で消去されました。
**安定した全体改善が確認できないため、コンパイルキャッシュは不採用**です。
Zig配布アーカイブのダウンロードキャッシュは既存どおり維持します。

テスト・OS・ビルドモードの単純削除や、PRだけの検証縮小は行っていません。
残る主要コストはReleaseSafeのコンパイルです。キャッシュmissの残因は未確定で、
推測を確定事項として扱いません。

## 最終構成の確認

[CI 42236457517](https://github.com/moribit/Akamata/actions/runs/42236457517)
（コード `9e2b233`）が **23/23成功**しました。

| 指標 | 変更前 | 最終構成 |
|---|---:|---:|
| 全体時間 | 17分56.5秒（4実行中央値） | **11分23秒（約36.6%短縮）** |
| 総ジョブ実行時間 | 90分15秒 | 92分30秒 |
| 必要なジョブ | 23 | 23 |
| living examplesコマンド数 / OS | 57 | 57 |
| CLI/Docker開始待ち（直近baseline） | 703秒 | 4秒 |

待ち時間削減が成果であり、総計算コストの削減とは主張しません。
最終構成でもmacOS living examplesのコンパイルが最長です。
5件の変更後成功実行で新たなflaky failureは観測していませんが、
有限回の検証であることは留保します。別workflowのTSanやリリース条件は変更せず、
PR/mainの完全検証を維持しています。
