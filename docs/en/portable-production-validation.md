# Portable Production Contract implementation report

Implementation starts at fc8e00e. Provider model and runtime architecture are retained; the work connects declarations to checked acquisition, local deployment validation and explicitly isolated live evidence. Native default remains Threaded. Reactor code/gate is unchanged.

1. **Initial wiring:** Contract/Provision and borrowed Context facades existed; Native jobs and Workers DO control required manual owner callbacks. R2 listing returned no portable continuation result and metadata lifetime depended on operation allocation.
2. **Ownership issues:** listing snapshots lacked one cleanup owner; queue context lacked instance-specific borrowing; custom realtime namespaces disagreed with the hardcoded gateway. These now have explicit page/owner/context/namespace contracts.
3. **Storage result:** additive Store.listPage owns keys, metadata and cursor through ListPage.deinit. Limits 1–1000, opaque same-store/prefix cursor, no mutation snapshot guarantee. Legacy list remains with its documented adapter-specific ownership.
4. **Storage parity:** Memory, filesystem and simulated R2 run shared pagination checks; native allocation-failure checks verify cleanup. Managed root/template bridge verifies HTTP/custom metadata, short-page continuation and handle closure. No live R2 listing certification is claimed.
5. **Native Queue:** jobs.Provider(Descriptor) adapts the existing persistent jobs.Queue, borrows Db/Consumer context, exposes Producer/worker and stops admission explicitly. Caller owns worker start/join. No replacement engine or hidden thread is introduced.
6. **Workers Queue:** QueueOwner copies the resolved binding and owns its typed Consumer view. The application forwards the existing managed dispatch hook; the reference explicitly calls setQueueConsumer. Owner destruction frees local state only.
7. **Delivery:** at-least-once, version/event ID/correlation/idempotency metadata, payload limits and actual backend attempt are preserved. Native counts failed deliveries/lease reclaim according to the existing jobs engine; Workers host attempts/retry/DLQ remain platform policy. No exactly-once or distributed transaction claim.
8. **Native Realtime:** realtime.Native owns registry/strings/synchronization; transports own sockets. Stop/drain callbacks before registry deinit.
9. **Workers Realtime:** RealtimeOwner maps existing Service operations to the private DO fetch control plane. Room names resolve through selected namespace IDs; portable connection IDs are lossless decimal u64 alongside legacy UUID attachments. Gateway authorization and explicit platform extensions remain.
10. **Lifecycle:** checked factories derive provider/binding and reject configuration drift before resource acquisition. Startup uses errdefer; Context borrows; stop/join precedes reverse deinit. Isolate shutdown does not imply a guaranteed destructor or remote deletion.
11. **Partial failure:** allocation-failure tests traverse DB + Store view + Realtime + Queue startup; earlier owned resources are released and caller-owned DB remains usable after queue-only failure.
12. **Environment:** root and named TOML environments are selected explicitly. Binding/vars are not silently inherited. Containers use Native providers and reject Workers environment overrides; persistence requires volumes.
13. **Drift:** missing/duplicate bindings, resource placeholders/identifiers, configured DB URL/provider mismatch and Realtime gateway namespace mismatch are detected. Queue producer declaration alone cannot prove consumer registration; producer-only applications remain valid. Custom glue, DO migrations, JSONC and artifact export proof remain explicit limitations.
14. **Readiness:** legacy status fields remain; declared/configured/validated are local evidence only. Reachable requires a real probe; ready requires an application smoke contract. Neither is inferred or emitted by offline inspection.
15. **Live design:** manual protected-environment workflow runs the existing reference against operator-attested dedicated resources with a <24h manifest, matching health marker, HTTPS/no redirects, bounded requests and exact test-effect cleanup. No automatic provisioning or broad remote deletion.
16. **Live execution:** not run; dedicated test deployment/manifest/credentials were not supplied. Guard tests prove missing isolation, expiry, host/resource mismatch fail before fetch. Infrastructure expiry/teardown is operator-owned; ambiguous POST failures can require purging the dedicated test DB.
17. **Evidence levels:** Unit / Adapter Contract / WASM Host Simulation / Live Provider Contract / Production Observed are separate. Current successes are the first three, not live or production evidence.
18. **CLI:** inspect capabilities and check accept environment/strict validation. Contract-aware deploy preflights before build/migration/deploy; named environments require metadata. Explicit Container preflight is honored. Placeholder D1 resources must be provisioned separately; environment migration fails closed.
19. **Diagnostics:** human inspection includes target/environment/provider/binding/problem and requiring routes; URLs are redacted. JSON retains route/provider metadata and adds environment/readiness. Inspection remains read-only.
20. **Reference:** device_messaging shares DB/storage/queue/realtime domain code and event descriptors across explicit Native and Workers entry-point owners. Real SQLite/filesystem/jobs integration observes delivery and cleanup; late delivery cannot recreate removed effects. Guestbook remains the smaller DB reference.
21. **Matrix:** [provider/owner/lifecycle/evidence matrix](portable-production-contract.md) covers database, storage, queue, realtime, outbound HTTP and crypto for Native/Workers/Container.
22. **Compatibility:** existing facades/manual factories/list/handler callbacks remain. Added Storage errors affect exhaustive downstream switches. Reference State/response IDs/cleanup endpoints change internally; report admission now depends on queue. Deploy implicit placeholder creation is intentionally removed. OpenAPI/HTTP client/protocol TS/C sources are unchanged.
23. **Regression evidence:** local Debug and ReleaseSafe Native tests, integration/tasks, Workers WASM, both reference builds, 22 compile-fail cases, CLI operations/capabilities, scaffold/update/sync protection, 99 socket contracts, isolation/session/stress/fault and JS bridge suites pass. Cross-platform CI and TSan results are recorded below once completed.
24. **Platform differences:** opaque cursor formats/optional metadata, host buffering, backend retry/DLQ, socket ownership, old DO attachments, secret configuration visibility and Container disk persistence remain explicit. DB/enqueue effects are not atomic; native typed queue owners are descriptor-specific.
25. **Next DX:** artifact-level consumer/glue wiring proof, full config parsing, safe named-environment migration routing and an operator-provided isolated live run. Extend current owners and tooling rather than introduce another framework.

## Threaded performance regression check

Three 3-second rounds, 32 keep-alive connections, ReleaseFast, loopback workstation. First candidate/baseline throughput differences: hello −1.6%, echo −2.2%, DB −4.1%. Repeating both binaries gave +0.4%, +0.8%, +0.8%; baseline itself drifted by more than the first candidate difference. This does not establish a performance improvement or a severe regression. Repeated P99 (baseline → candidate): hello 0.723 → 0.800 ms, echo 0.902 → 0.770 ms, DB 2.496 → 2.603 ms. RSS remained about 7–8 MiB. Raw timings/commands/environment/binary hashes are [retained](../evidence/portable-production/reproduce.md). No HTTP/runtime hot path changed.
