# Akamata v0.1.5

Released 2026-10-03. Requires **Zig 0.17.0**.

## Changes

- Migrate removed C imports and array repetition, reflection, tuple types, sentinel string APIs, and build run-argument forwarding to Zig 0.17.
- Fix borrowed byte-array SQL values in optimized builds and verify stored contents.
- Update CI, Native/Workers scaffolds, container toolchains, and documentation.
- Add checkout scaffold coverage, including the public build helper; retain update/sync and Workers capability regressions.

## Upgrade

Use Zig 0.17.0 and rebuild the CLI. Update application `build.zig` argument forwarding and its minimum Zig version, then run `akamata update --to=v0.1.5 --sync` with the new CLI. Application code using removed Zig APIs needs its own migration.

Read the [English migration guide](../en/zig-0.17-migration.md) or [日本語の移行ガイド](../ja/zig-0.17-migration.md) for changes, commands, and validation scope.

## Validation

All 140 unit tests pass in Debug and ReleaseSafe. HTTP integration, tasks, compile-fail diagnostics, Workers JavaScript regressions, generated Native/Workers apps, update/sync, OpenSSL, and Linux musl cross-builds were verified locally.

Release automation builds chat example archives for x86_64/aarch64 Linux musl and macOS. These archives contain the chat executable; build the CLI from the repository with `zig build cli`.
