ZIG WEB FRAMEWORK

Akamata

Zig 0.17 向けの、明快で軽量な Web framework。portable で、本番運用に必要な機能を備えています。

HTTP · WebSocket · SQLite · D1 · Turso · native · Workers · Containers

01
コンセプト

ひとつのコードベース、3つの runtime

アプリケーションコードを保ったまま、用途に合った実行環境を選べます。

Native

SQLite、SSE、native WebSocketを使ったローカル開発とサーバ運用。

Cloudflare Workers

WASM entry point、D1、JSPI、Durable Object WebSocket。

Cloudflare Containers

長時間動作する native process が必要な workload へ。

明示的な境界

runtime固有の entry point は明示し、handler code は共有。

02
Developer experience

Zig らしい最初の handler

const State = struct {};
const Ctx = am.Context(State);

fn hello(c: *Ctx) !void {
    try c.text("Hello, Akamata!");
}

_ = try app.get("/", hello);

型付き application state

App、Context、request parsing、response helper、middleware、model、repositoryを State type に結び付けます。

明示的な ownership

request data は request arena に置かれ、error は Zig の error として扱います。

03
Database portability

同じ facade、異なる地形

SQLite

Bundled native SQLite。local-firstな開発と単一process serviceに。

D1

JSPI bridge経由の Cloudflare binding。statement 実行ごとに1 suspend。

Turso / libSQL

HTTP pipelineで remote・multi-region workloadに接続。

Model + migration

型付き schema、repository、versioned migration、startup helper。

変わるのは handler より deployment URL です。

04
Observability

request の時間の使い道を見える化

GET /api/news
total        43.8 ms
├─ framework  1.2 ms
├─ middleware 0.3 ms
├─ db         38.7 ms
└─ serialize   0.6 ms

request 単位の timing

monotonic clock、request ID、route template、軽量な nested span。

本番向けの出力

Prometheus metrics、structured access log、opt-in の Server-Timing。

05
Web APIs

実用的な building blocks

  • Routing: typed params、query、JSON、form、multipart parsing
  • Middleware: request ID、auth、session、CSRF、CORS、rate limit、secure headers
  • Realtime: native WebSocket と SSE、Workers Durable Object integration
  • Outbound: high-cardinality labelを避けた HTTP client instrumentation

frameworkは小さく、application policyは利用者に委ねます。

06
最初の一歩

install から最初の request まで

git clone https://github.com/appleuser634/Akamata.git
cd Akamata && ./scripts/install.sh
cd ~/projects
akamata init myapp --target=both
cd myapp
zig build run

学習しやすい scaffold

Note model、CRUD route、health endpoint、migration、Workers glue、deploy fileを生成。

読んで置き換えられる

生成された source を読み、stateを置き換えても同じ handler shapeを保てます。
